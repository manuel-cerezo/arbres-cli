# Datos y licencias

`arbres` no incluye datos: los descarga de [arbres.barcelona](https://arbres.barcelona), que los prepara a partir de estas fuentes. Cada respuesta con `--json` lista en `fuentes` las que ha usado.

| Datos | Fuente | Licencia |
|---|---|---|
| Árboles de Barcelona (calles, parques y zonas verdes) | [Ajuntament de Barcelona, Open Data BCN](https://opendata-ajuntament.barcelona.cat/data/ca/dataset/arbrat-viari) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| Árboles de L'Hospitalet de Llobregat | [Ajuntament de L'Hospitalet, dades obertes](https://dadesobertes.seu-e.cat/dataset/hospitaletdellobregat-arbres) | [CC BY-ND 4.0](https://creativecommons.org/licenses/by-nd/4.0/) |
| Padrón y superficie de barrios | Ajuntament de Barcelona, Open Data BCN | CC BY 4.0 |
| Textos de las fichas de especie | Wikipedia | CC BY-SA |
| Floración, origen y hoja | Fichas de arbres.barcelona, con sus fuentes citadas en la web | Ver arbres.barcelona |
| Alergenicidad del polen | Cariñanos y Marinangeli (2021) | Cita académica |

Si reutilizas lo que devuelve el CLI, cita la fuente: por ejemplo, «Datos: Ajuntament de Barcelona (CC BY 4.0), vía arbres.barcelona, versión 2026-11-03».

Los datos de L'Hospitalet tienen licencia *sin obras derivadas* (ND): puedes citarlos y mostrarlos tal cual, con atribución, pero no publicar versiones modificadas del conjunto de datos.
